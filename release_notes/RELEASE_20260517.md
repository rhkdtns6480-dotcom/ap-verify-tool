# Release Notes — 2026-05-17

## AP Auto Verification Tool v0.0.1

---

### 신규 기능

#### Packet S/D 탭
- UDP 패킷 송수신 테스트 모듈 신규 구현
- 동작 모드: S→R / R→S / 양방향 / 송신만 / 수신만
- 토폴로지 Master/Slave 인터페이스 자동 연동 (IP 자동 채우기)
- 포트 자유 입력 (Src: 0=랜덤, Dst: 기본 19999)
- PPS / Mbps / 최대속도 / 패킷수 / 시간 / 지속 전송 설정
- NAT 세션 선개통: Slave 선송신 → NAT Port 자동 파악 → Master 응답
- 실시간 통계 박스: 송신 / 수신 / 손실 / 평균RTT / 처리량 / 지터
- 미니 토폴로지: Sender[S]/Receiver[R] 강조, 방향 화살표
- 임계값 알람 (손실률/RTT/지터), 5초 주기 경고 (로그 폭주 방지)
- 동작 로그 (Syslog 연동)

#### UI 레이아웃
- 검증 실행 탭 신규 추가
- 탭 이름 변경: 기능 검증 시나리오 / 규격 검증 시나리오 / 결과서 설정
- 상태 요약 패널: 토폴로지 우측 (Master/Slave/DUT AP 요약)
- Packet S/D: 좌측 설정(스크롤) + 우측 결과/미니토폴로지/로그 구조

### 버그 수정

#### Packet S/D 수신률 86% 손실 버그
- 원인: BPF 필터 `udp dst port 19999`만 지정 → Sender 자신의 송신 패킷이 수신으로 카운트
- 수정: `udp dst port 19999 and dst host {my_ip}` 필터 강화
- 추가: Src IP == my_ip 루프백 패킷 명시적 drop

#### 기타
- PacketSDTab `setting_frame` / `top` NameError 수정 (구버전 코드 잔재 제거)
- `DEFAULT_PORT` 미정의 오류 수정
- `_sender_var_cb` 참조 오류 수정
