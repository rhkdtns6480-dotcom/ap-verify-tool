# Release Note — v0.0.1 (2026-05-10)

## 최초 릴리즈 (Initial Release)

---

### 전체 구조

- **Python** 3.14 / **Tkinter** GUI (6탭 커스텀 탭바)
- **Plugin Architecture** — DHCP / NAT / IGMP / Packet S/D (더미 구현)
- **Scapy 2.7.0** 기반 실제 패킷 송수신
- **PyInstaller** exe 빌드 지원 (Scapy 전체 번들)

---

### 구현된 기능

#### 토폴로지 탭
- PC 인터페이스 자동 감지 (psutil)
- Master / Slave / 미지정 역할 지정
- 인터페이스별 IP 설정 (고정/동적/서버)
- 실시간 패킷 애니메이션 (OK/지연/실패 색상 구분)
- **🔗 연결상태 확인** — Scapy L2(srp) ARP + ICMP Ping (지정 인터페이스 직접 송신)
- **📡 AP 감지** — ARP 스캔으로 DUT AP 위치 및 NAT/Bridge Mode 자동 판별
- **가상 MAC 관리** — OUI 프리픽스 기반 가상 MAC 최대 50개 생성, 병렬 DHCP 요청

#### 기능 검증 탭
- DHCP / NAT / IGMP / Packet S/D 플러그인 선택
- 플러그인별 표준 검증 항목 미리보기 (RFC 기준)
- 추후 실제 검증 로직 연결 예정

#### 시나리오 검증 탭
- Step 편집기 (Send / Wait / Check / Delay / Assert)
- 반복 테스트 — 횟수 지정 or 시간 지정(Aging, 최대 999시간)
- 반복 간 대기 시간 설정
- 실행 현황 실시간 표시 (PASS/FAIL, RTT, 경과 시간)
- 시나리오 JSON 저장/불러오기

#### Syslog 탭
- DEBUG / INFO / WARN / ERROR 레벨 필터
- 키워드 검색, 자동 스크롤 ON/OFF
- `.log` 파일 저장 (RotatingFileHandler, 10MB/5개)
- 로그 경로: `%APPDATA%\APVerifyTool\logs\ap_verify_YYYYMMDD.log`

#### 결과서 탭
- Excel (.xlsx) — Summary / 플러그인별 시트 / RawLog 시트 자동 생성
- PDF — 표지 / 요약 / Step 상세 / FAIL 목록 (reportlab)
- 장비명, 펌웨어, 담당자, 저장 경로 설정

#### 환경설정 탭
- 보고서/로그 저장 경로 설정
- 인터페이스 감지 주기, 패킷 타임아웃 설정

---

### Npcap 자동 설치 지원
- 앱 시작 시 Npcap 설치 여부 자동 체크 (레지스트리 + 드라이버 파일)
- 미설치 시 안내 다이얼로그 표시
- `npcap-*.exe`가 exe 옆에 있으면 **silent 자동 설치** (`/S /winpcap_mode=yes`)
- 타이틀바에 모드 배지 표시: `● 실제 패킷 모드` / `● 시뮬레이션 모드`
